# 垂直领域 Agent

通用 Agent 在垂直场景下往往力不从心。本章按场景拆解，每类垂直 Agent 都有自己的设计模式与技术栈。

## 本章内容

- [编程 Agent](./coding-agent) — 代码生成、修改、重构、调试的 Agent 设计模式
- [深度研究 Agent](./deep-research) — 多轮检索、综合、引用的研究型 Agent
- [浏览器与电脑操作 Agent](./browser-agent) — 屏幕操作、网页交互的 Agent
- [语音 Agent](./voice-agent) — 实时对话、打断、情感的语音 Agent
- [数据分析 Agent](./data-analysis) — 代码解释器模式与数据可视化
- [客服 Agent](./customer-service) — 多轮对话、知识库、工单系统集成

## 学习路径

按你的业务场景直接进入对应章节。每一类 Agent 都有自己独立的最佳实践与陷阱。
