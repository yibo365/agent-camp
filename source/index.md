# Agent 源码解析

读源码是最快的学习路径。本章选取业界标杆 Agent 项目，做架构剖析与核心循环解读。

## 本章内容

- [Claude Code 架构剖析](./claude-code) — Anthropic 官方 CLI Agent 的设计哲学
- [Codex CLI 源码](./codex-cli) — OpenAI 的开源 Coding Agent
- [Cursor Agent 模式](./cursor) — Cursor 内部 Agent 模式的公开实现细节
- [Cline / Roo Code](./cline) — VSCode 生态最流行的开源 Coding Agent
- [OpenHands (OpenDevin)](./openhands) — 开源 Devin 复刻
- [Aider 代码编辑策略](./aider) — Diff / Edit Block / Whole File 三种编辑策略
- [SWE-agent](./swe-agent) — 学术界 SOTA Coding Agent
- [GPT Engineer / GPT Pilot](./gpt-engineer) — 从零生成项目的 Agent
- [pi-mono / pyMono](./pi-mono) — 轻量 Mono 仓 Agent 实现
- [Browser Use / Operator](./browser-use) — 浏览器自动化 Agent

## 学习路径

1. 想理解 Agent 设计哲学，从 **Claude Code** 与 **Codex CLI** 入手
2. 想理解 IDE 内 Agent 实现，看 **Cursor** 与 **Cline**
3. 想了解学术前沿，看 **SWE-agent**
4. 想做浏览器 Agent，看 **Browser Use**
