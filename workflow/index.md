# 流程编排

并非所有任务都需要 Agent，许多场景下确定性更高的 Workflow 才是正确答案。本章覆盖主流编排框架与设计模式。

## 本章内容

- [LangGraph 深度解析](./langgraph) — 图节点、状态、边三件套与生产实战
- [LlamaIndex Workflows](./llamaindex-workflows) — 事件驱动的编排范式
- [Dify / Coze / FastGPT](./dify) — 低代码可视化编排平台对比
- [编排模式](./patterns) — 顺序 / 并行 / 条件 / 循环 / 人工介入
- [工作流与 Agent 的边界](./workflow-vs-agent) — 何时该用工作流，何时该升级 Agent

## 学习路径

1. 先看 **工作流与 Agent 的边界**，建立"选对工具"的判断力
2. 学习 **LangGraph**，掌握业界最主流的编排框架
3. 对照 **Dify / Coze** 等低代码平台，理解可视化编排的能力边界
