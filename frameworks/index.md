# 主流 Agent 框架

2024-2026 年涌现的 Agent 框架数十种。本章选取 10 个主流框架，做架构剖析与选型指南。

## 本章内容

- [LangChain / LangGraph](./langchain) — 生态最大、组件最全的老牌框架
- [LlamaIndex](./llamaindex) — RAG 起家，已扩展为完整 Agent 框架
- [Claude Agent SDK](./claude-agent-sdk) — Anthropic 官方 Agent SDK
- [AutoGen (Microsoft)](./autogen) — 多 Agent 对话框架代表
- [CrewAI](./crewai) — 角色化 Agent 协作的轻量框架
- [Semantic Kernel](./semantic-kernel) — Microsoft 企业级 .NET / Python 框架
- [Pydantic AI](./pydantic-ai) — 类型安全优先的 Python Agent 框架
- [Agno](./agno) — 前身 Phidata，主打高性能多模态
- [OpenAI Agents SDK / Swarm](./openai-agents-sdk) — OpenAI 官方多 Agent 框架
- [框架选型决策树](./comparison) — 业务场景 → 框架推荐矩阵

## 学习路径

1. 入门首选 **LangChain / LangGraph**，社区最大、问题最容易找到答案
2. RAG 场景优先看 **LlamaIndex**
3. 企业 / 多 Agent 协作场景看 **AutoGen** 或 **CrewAI**
4. 选型时对照 **决策树**，避免盲目跟风
