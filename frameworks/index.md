# 主流 Agent 框架

2024-2026 年涌现的 Agent 框架数十种。本章选取 8 个主流框架，做架构剖析与选型指南。

## 本章内容

- [LangChain / LangGraph](./langchain) — 生态最大、组件最全的老牌框架
- [LlamaIndex](./llamaindex) — RAG 起家，已扩展为完整 Agent 框架
- [Claude Agent SDK](./claude-agent-sdk) — Anthropic 官方 Agent SDK
- [OpenAI Agents SDK / Swarm](./openai-agents-sdk) — OpenAI 官方多 Agent 框架
- [OpenClaw](./openclaw) — 本地优先、全平台个人 AI 助手网关
- [Hermes Agent](./hermes-agent) — Nous Research 出品，自我进化的自主 Agent
- [Pi](./pi) — 极简内核、极致可扩展的终端编程 Agent
- [框架选型决策树](./comparison) — 业务场景 → 框架推荐矩阵
- [Agent 框架选型面试深挖](./framework-selection-interview) — 自研薄封装 vs LangGraph / OpenAI Agents SDK 的工程取舍

## 学习路径

1. 入门首选 **LangChain / LangGraph**，社区最大、问题最容易找到答案
2. RAG 场景优先看 **LlamaIndex**
3. 想要个人 AI 助手落地看 **OpenClaw** 或 **Hermes Agent**
4. 编程 Agent / 终端工作流看 **Pi**
5. 选型时对照 **决策树**，准备面试追问时看 **Agent 框架选型面试深挖**
