# Multi-Agent 系统

单 Agent 撞墙时，Multi-Agent 是常见的破局方向。本章覆盖架构模式、通信协议与经典案例。

## 本章内容

- [多 Agent 架构模式](./patterns) — 层级、网络、监督者、蜂群四种模式
- [Agent 通信协议](./communication) — A2A（Google）、ACP、AGNTCY 三大协议对比
- [调度者-工作者模式](./orchestrator-worker) — 业界最常用的多 Agent 模式
- [Agent 协作策略](./collaboration) — 辩论、投票、角色扮演、评审者
- [MetaGPT / ChatDev 案例](./metagpt-chatdev) — 软件公司模拟器的代表作

## 学习路径

1. 先理解 **架构模式**，避免一上来就堆 Agent
2. 重点掌握 **调度者-工作者模式**，覆盖 80% 生产场景
3. 跨组织 / 跨系统协作场景必读 **A2A 协议**
